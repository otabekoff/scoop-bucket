# Scoop bucket for Pleno

[Pleno](https://pleno.mohirlab.uz) is a readable programming language with optional checked types and async built in.

```powershell
scoop bucket add pleno https://github.com/otabekoff/scoop-bucket
scoop install pleno
```

This installs `pleno`, `plm`, `pleno-lsp`, `pleno-dap` and `pleno-repl`. The manifest is kept in the [Pleno repository](https://github.com/otabekoff/pleno/tree/main/packaging/scoop).
